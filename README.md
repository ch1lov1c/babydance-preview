# BabyDance

Демонстрационная главная страница школы спортивных бальных танцев в Сургуте. Дизайн-концепция WEBNICSS®.

Статический сайт без сборки. Для локального просмотра откройте `index.html` или запустите в каталоге проекта `python -m http.server 8080`. Для GitHub Pages выберите публикацию из корня ветки `main`.

Фотографии сгенерированы для концепции. Запись ведёт в публичное сообщество школы или на её телефон.
